# FreeCode AI

FreeCode AI is an open, multi-provider AI coding extension for Visual Studio Code.

## Features
- **Multi-Provider Support**: Google Gemini, Groq, OpenRouter, and Ollama.
- **Smart Model Routing**: Automatic fallback and cooldown management.
- **Inline Autocomplete**: Fast Fill-in-the-Middle code completions.
- **Diagnostics & Error Explanation**: Instant fixes and code explanations.
- **Autonomous Coding Agent**: Multi-step file and workspace tools.
